# Chromium test runtime

Browser QA serves built frontend assets through scripts/qa-web-server.mjs,a loopback-only Node HTTP server. Build first with npm run build before qa:e2e; test:login builds automatically. Playwright starts the built Nest API separately and sets existing QA_API_PORT for the proxy. /api/*,/healthz,/readyz requests stream to that real API with method,query,Origin,body and Set-Cookie preserved. No synthetic backend replaces application behavior. Browser assertions,isolated databases,strict selected ports,one worker,zero retries and reuseExistingServer:false remain.

The QA static server resolves paths beneath apps/web/dist,denies dotfiles/traversal and non-read static methods,serves appropriate built-asset MIME/HEAD responses and emits generic502 on unavailable API. It requires a built index.html. It has no production hosting role,new dependency or new environment variable. npm run dev remains the normal development server. npm run test:qa-web executes real HTTP regressions for static paths/MIME/HEAD and proxy method/query/origin/body/cookies/health/error behavior; CI runs this after the build.

Motivation/evidence: repeated Windows native exits3221226505 affected Vite dev,one preview startup and a later preview request; exact native root cause remains unproven. The earlier Vite-preview experiment is superseded. Plain Node removes the Vite/native-transform layer from browser serving and verifies generated assets. Failed attempts remain in QA_EXECUTION_REPORT.md and ignored logs; the new default all-group run and exact-head CI must pass independently. Do not call preview a proven crash fix or delete failed records.

Background references consulted22 November2026: [built-site testing](https://vite.dev/guide/static-deploy),[preview proxy/strict-port defaults](https://vite.dev/config/preview-options). These informed the superseded preview experiment; current serving/proxy behavior is defined by the checked-in Node script and its executable tests,not Vite preview.
